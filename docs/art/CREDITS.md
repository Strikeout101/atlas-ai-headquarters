# ATLAS art credits

Third-party assets used in the ATLAS 3D office (`public/models/atlas`, `public/hdri`, `public/textures`).
Sources are kept in `Downloaded-Models/` (git-ignored); models are resized, simplified and re-textured by the scripts in `art/blender/`.

> **Licence note.** Most Sketchfab models below are **CC BY-NC 4.0 (non-commercial)**. They are fine for a personal, self-hosted ATLAS. Replace them before any commercial use or public distribution. The executive chair uses the **Sketchfab Standard** licence, which does not allow the raw model to be extractable — replace it before sharing ATLAS with anyone. This note is not legal advice.

## Characters

- Director 3D character (`public/models/atlas/director.glb`): the owner's avatar made with [Avaturn](https://avaturn.me) (`Downloaded-Models/characters/director/NewCEO.glb`), retargeted by `art/blender/build_atlas_director_avaturn.py`. Check Avaturn's terms before sharing ATLAS publicly.
- Director animations: [Universal Animation Library](https://quaternius.com) by Quaternius (CC0) — idle, walk, jog, sprint, talking, sitting, interact, dance clips, retargeted to the avatar's skeleton.
- Director walking sprite: custom (project owner); kept as the fallback for the 3D character.
- Agents (3D), built by `art/blender/build_atlas_agents.py`, animated with the Universal Animation Library: Microsoft Rocketbox avatars (MIT), see below. (Earlier ActorCore, Joe and floral-dress agents are retired and no longer shipped.)
- Agent sprites (fallback while 3D models load): from the original Claw-Empire project.
